# FoundF 项目最终目标（最高约束）

> 本文件由项目所有者于 2026-07-19 确立，是所有开发任务的最高约束。
> 任何 Phase 计划、功能开发、重构都必须以本文件为准；冲突时本文件优先。

## 定位

FoundF 不是普通量化脚本，也不是数据展示系统。

它是：**部署在 NAS Docker 上、长期运行的个人 AI 投研系统**。

核心目标：建立一个能够长期积累数据、分析个人投资组合、辅助投资决策、持续优化量化策略的 **AI Investment Operating System**。

## 核心能力目标

### 1. 长期金融数据资产库

长期自动收集并本地保存（10 年以上持续积累的个人金融数据库，非临时查询）：

- **A股**：全市场股票基础信息、日线、分钟级（能力允许时）、ETF、指数、行业、财务、公司公告、重大事件
- **港股**：港股通股票池、价格、公司公告、财务
- **美股**：股票价格、指数、ETF、财报、宏观数据

数据要求：本地保存、可追溯、可重新计算、持续增量更新。

架构分层：

```
Raw Data → Clean Data → Feature Data → Strategy Data → AI Analysis Data
```

### 2. 个人投资组合智能分析

系统必须理解：当前持仓、历史交易、成本、买卖逻辑、风险偏好。

每天自动分析：

- **持仓状态**：当前市值、盈亏、仓位比例、行业集中度、风险暴露
- **个股分析**（每只股票）：
  - 基本面：财务质量、成长能力、估值水平
  - 技术面：趋势、动量、波动
  - 量化：因子评分、历史分位
  - 风险：新闻风险、行业风险、公司风险

输出不是简单的买/卖，而是 **Investment Memo**：当前观点、理由、风险、需要关注事项。

### 3. 长期稳定投资量化策略

目标是长期稳定收益，不是高频交易。采用市场成熟的多因子模型：

Value / Quality / Growth / Momentum / Low Volatility / Size

- 参考世界成熟量化投资体系
- **禁止自行创造大量无验证因子**
- 每个因子必须：有定义、有数据来源、有历史回测、有 IC 分析、有稳定性验证
- 组合目标：降低最大回撤和波动率，提高风险调整收益

### 4. AI 重大信息风险管理（Risk Intelligence Engine）

每天收集：

- 公司：公告、财报、业绩预告、管理层变化
- 行业：政策、监管、供需变化
- 宏观：利率、汇率、通胀、流动性

AI 分析是否影响盈利、估值、行业趋势，输出 0-100 风险等级及原因。

### 5. 每日自动复盘闭环

每日收盘后自动运行：

```
更新行情 → 更新数据库 → 重新计算因子 → 分析持仓
→ 扫描重大信息 → 运行风险模型 → 运行策略模型 → 生成日报
```

日报内容：今日市场总结、我的组合变化、策略信号变化、风险提醒、AI 复盘。

保存至 `reports/YYYY-MM-DD.md`。

### 6. 信息源自动学习和淘汰

不永久相信任何信息源。每个来源建立评分，记录：source、预测内容、实际结果、准确率。

长期提高高质量来源权重、降低低质量来源权重，最终自动减少垃圾信息影响。

### 7. 量化策略持续优化（Strategy Evolution System）

流程：

```
策略版本 → 历史回测 → Walk Forward 验证 → 实盘模拟 → 效果评价 → 保留优秀版本
```

评价维度：收益、Sharpe、最大回撤、稳定性、换手率。

**禁止只优化历史最高收益，防止过拟合。**

### 8. NAS Docker 长期运行

要求：自动启动、自动更新、自动备份、日志管理、数据检查。

服务拆分：data collector / database / strategy engine / AI engine / scheduler / API / dashboard。

数据每日增量；分钟数据长期积累。

## 开发原则

不要为了完成 Phase 而增加代码。每次开发必须回答：

1. 是否增加投资决策能力？
2. 是否增加数据资产？
3. 是否提高风险控制能力？
4. 是否提高长期收益稳定性？

如果没有明显价值，不开发。

优先级（高 → 低）：

1. **数据可靠性**
2. **投资组合分析**
3. **风险控制**
4. **量化策略**
5. **AI 智能化**
